Files starting with `_` are drafts: they are never listed or published. Copy this file to
`posts/<kebab-case-slug>.mdx` to publish a post at `/blog/<slug>/`.

Everything a cheatsheet can use works here too: headings (which build the table of contents),
code fences, tables, `<Note>`, math and so on.
