Symbols used across the maths and physics sheets, grouped the way appendix B of the
_No bullshit guide_ groups them. See [math fundamentals](/maths/math-fundamentals/) for the formulas.

## Math notation

| Symbol                         | Meaning                                         |
| :----------------------------- | :---------------------------------------------- |
| $=$, $\neq$                    | equal, not equal                                |
| $\approx$, $\propto$           | approximately equal, proportional to            |
| $\equiv$                       | identically equal, or defined as                |
| $<$, $\le$, $>$, $\ge$         | less than (or equal), greater than (or equal)   |
| $\pm$, $\mp$                   | plus or minus; the opposite sign in the same formula |
| $\Rightarrow$, $\Leftrightarrow$ | implies; if and only if                       |
| $\therefore$, $\because$       | therefore, because                              |
| $\infty$                       | infinity                                        |
| $\lvert x \rvert$              | absolute value                                  |
| $\lfloor x \rfloor$, $\lceil x \rceil$ | floor, ceiling                          |
| $n!$                           | factorial $n(n-1)\cdots 2 \cdot 1$              |
| $\binom{n}{k}$                 | binomial coefficient $\dfrac{n!}{k!(n-k)!}$     |
| $\sum_{i=1}^{n} a_i$           | sum $a_1 + a_2 + \cdots + a_n$                  |
| $\prod_{i=1}^{n} a_i$          | product $a_1 a_2 \cdots a_n$                    |
| $\sqrt{x}$, $\sqrt[n]{x}$      | square root, $n$-th root                        |
| $e$, $\pi$, $i$                | $2.71828\ldots$, $3.14159\ldots$, $\sqrt{-1}$   |
| $f(x)$, $f^{-1}(x)$            | function of $x$, its inverse                    |
| $\ln x$, $\log_b x$            | natural log, log base $b$                       |
| $\deg$, $\mathrm{rad}$         | degrees, radians                                |
| $\text{Q.E.D.}$ or $\blacksquare$ | end of proof                                 |

| $\mathbb{R}^n$             | $n$-tuples of reals                        |

## Complex numbers notation

| Symbol                        | Meaning                                                |
| :---------------------------- | :----------------------------------------------------- |
| $i$                           | imaginary unit, $i^2 = -1$                             |
| $z = a + bi$                  | Cartesian form; $\operatorname{Re}(z) = a$, $\operatorname{Im}(z) = b$ |
| $\bar{z}$ or $z^*$            | conjugate $a - bi$                                     |
| $\lvert z \rvert$             | modulus $\sqrt{a^2 + b^2} = \sqrt{z\bar{z}}$           |
| $\arg z$ or $\varphi$         | argument, the angle from the positive real axis        |
| $z = r(\cos\varphi + i\sin\varphi)$ | polar form, $r = \lvert z \rvert$              |
| $z = re^{i\varphi}$           | exponential form                                       |
| $e^{i\theta} = \cos\theta + i\sin\theta$ | Euler's formula                             |
| $z^n = r^n e^{in\varphi}$     | de Moivre                                              |

## Vectors notation

| Symbol                              | Meaning                                              |
| :---------------------------------- | :--------------------------------------------------- |
| $\vec{v}$ or $\mathbf{v}$           | a vector                                             |
| $(v_x, v_y, v_z)$                   | components                                           |
| $\hat{\imath}, \hat{\jmath}, \hat{k}$ | unit vectors along $x$, $y$, $z$                   |
| $\vec{v} = v_x\hat{\imath} + v_y\hat{\jmath} + v_z\hat{k}$ | component form               |
| $\lVert \vec{v} \rVert$ or $\lvert \vec{v} \rvert$ | magnitude $\sqrt{v_x^2 + v_y^2 + v_z^2}$ |
| $\hat{v}$                           | unit vector $\vec{v} / \lVert \vec{v} \rVert$        |
| $\vec{u} \cdot \vec{v}$             | dot product $u_x v_x + u_y v_y + u_z v_z = \lVert\vec{u}\rVert \lVert\vec{v}\rVert \cos\theta$ |
| $\vec{u} \times \vec{v}$            | cross product, magnitude $\lVert\vec{u}\rVert \lVert\vec{v}\rVert \sin\theta$, right-hand rule |
| $\vec{0}$                           | zero vector                                          |
| $\vec{v}_\parallel$, $\vec{v}_\perp$ | components parallel and perpendicular to a reference |

## Mechanics notation

| Symbol                | Quantity                        | SI unit          |
| :-------------------- | :------------------------------ | :--------------- |
| $t$                   | time                            | s                |
| $x$, $\vec{r}$        | position                        | m                |
| $\vec{v}$, $v$        | velocity, speed                 | m/s              |
| $\vec{a}$, $g$        | acceleration, gravitational acceleration | m/s²    |
| $m$                   | mass                            | kg               |
| $\vec{F}$, $\vec{N}$, $\vec{T}$ | force, normal force, tension | N           |
| $\mu_s$, $\mu_k$      | static, kinetic friction coefficient | none        |
| $\vec{p}$             | momentum $m\vec{v}$             | kg·m/s           |
| $W$, $K$, $U$, $E$    | work, kinetic, potential, total energy | J         |
| $P$                   | power                           | W                |
| $\theta$, $\omega$, $\alpha$ | angle, angular velocity, angular acceleration | rad, rad/s, rad/s² |
| $\tau$, $L$, $I$      | torque, angular momentum, moment of inertia | N·m, kg·m²/s, kg·m² |
| $k$, $T$, $f$, $A$    | spring constant, period, frequency, amplitude | N/m, s, Hz, m |

## Calculus notation

| Symbol                                    | Meaning                                   |
| :---------------------------------------- | :---------------------------------------- |
| $\lim_{x \to a} f(x)$                     | limit of $f$ as $x$ approaches $a$        |
| $x \to a^+$, $x \to a^-$                  | from the right, from the left             |
| $\Delta x$, $dx$                          | finite change, infinitesimal change       |
| $f'(x)$, $\dfrac{df}{dx}$, $\dot{x}$      | derivative (Lagrange, Leibniz, Newton for time) |
| $f''(x)$, $\dfrac{d^2 f}{dx^2}$, $\ddot{x}$ | second derivative                       |
| $\dfrac{\partial f}{\partial x}$          | partial derivative                        |
| $\int f(x)\,dx$                           | antiderivative, indefinite integral       |
| $\int_a^b f(x)\,dx$                       | definite integral, area under $f$ from $a$ to $b$ |
| $F(x) \big\vert_a^b$                      | $F(b) - F(a)$                             |
| $\sum_{n=0}^{\infty} a_n$                 | infinite series                           |
| $\nabla f$                                | gradient                                  |
